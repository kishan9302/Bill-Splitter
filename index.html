              Why Standard Splitters Drop Money
            

            

              When splitting ₹100.00 among 3 people, 100 ÷ 3 = 33.3333...
              If rounded down to ₹33.33 each, 3 × ₹33.33 = ₹99.99, leaving 1 paisa lost!
            

          


          

            How RupeeSplit Solves It Down to the Paisa:
          

          
    
            
  1. All amounts are converted to integer paise (₹1 = 100 paise).
    2. 
            
  2. We compute the base share: Math.floor(Total / People).
    3. 
            
  3. We find the remainder: Total % People.
    4. 
            
  4. The remainder paise are allocated 1 paisa (+₹0.01) each to the first participants so that the individual shares sum up exactly to the total bill.
